# OBILD (Ontology-Based Instructional Lesson Designer)

독서전략 기반 교과 수업지도안 자동 생성 시스템 (오프라인 테스트 버전)

## 1. 프로젝트 개요
2022 개정 중학교 사회과 교육과정 온톨로지(`사회과.ttl`), PISA 텍스트 분류(`text.ttl`), KNU 독서기능 및 전략(`readstrategy.ttl`), 가네의 9가지 수업사태(`가네.ttl`)를 통합 추론하여 맞춤형 읽기자료와 수업지도안을 자동 설계하는 시스템입니다.

## 2. 주요 기능
- **오프라인 우선 (Offline-First):** 외부 클라우드나 원격 서버 연결 없이도 로컬 환경에서 100% 작동
- **교육과정 탐색기:** 사회과 11개 영역, 핵심 아이디어, 내용 요소, 역량 다중 선택
- **읽기자료 생성기:** PISA 체재 및 유형 추론, 글자 수 슬라이더(300~800자), 오프라인 템플릿 생성기 및 Gemini API 연동
- **독서전략 추천기:** 텍스트 유형 대응 15개 독서기능 활성화, 1~3개 맞춤 전략 추천
- **가네 9사태 빌더:** 단계별 자동 슬롯팅 및 초안 생성, 인라인 편집
- **공문 서식 미리보기 & PDF/인쇄:** 학교 공식 교수·학습 과정안 표 출력 및 PDF 다운로드
- **관리자 포털:** TTL 지식베이스 통계, 4.3절 매핑 규칙 외재화 편집, 사용자 승인 관리

## 3. 로컬 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
pnpm install

# 2. 온톨로지 및 추론 엔진 단위 테스트 실행
pnpm test

# 3. 로컬 개발 서버 구동
pnpm dev
```

브라우저에서 `http://localhost:3000`에 접속하여 테스트할 수 있습니다.
- 교사 포털: `http://localhost:3000/teacher`
- 관리자 포털: `http://localhost:3000/admin`
- 상단 네비게이션 우측에서 [교사 / 관리자] 역할을 즉시 전환할 수 있습니다.
